## 決定(2026-09-28)

| 決定 | 結果 |
|---|---|
| 舊實驗目錄 | 改名,`run.yaml` 快照的 `run_name` 一起改 |
| 測試資料夾 | 維持一層,用檔名前綴(`test_quant_*`)區分,不照 `salt_core` 子資料夾分 |
| config key 檢查 | 做,跟旋鈕改名一起放在 8.1 |
| 分幾步 | 8.1 改名搬檔、8.2 salt_core 說明文字、8.3 example/data/viz 說明文字、8.4 文件 |

理由:

- 舊實驗改名:舊名字寫死在 `golden_output.py`、5 個 notebook、3 份文件,不改就永遠清不掉;只動目錄名跟
  一個欄位,權重檔不碰。
- 測試一層:已經有 `test_quant_calibrate`、`test_quant_convert` 這種前綴慣例,29 個檔一層看得清楚;分資料夾
  還要處理共用的 `_reference.py`、`_small_network.py` 的 import。
- config key 檢查:旋鈕改名後,寫舊 key 的 yaml 會被靜默忽略;`train`、`data` 這幾節打錯字(例如
  `weight_decy`)也一樣。層的 key 已經是嚴格的,補齊其餘幾節。
- 分四步:改名搬檔會動到很多 import,先單獨驗證;說明文字改寫不動程式邏輯,按資料夾分兩批;文件最後寫,
  名字都定了才寫得準。

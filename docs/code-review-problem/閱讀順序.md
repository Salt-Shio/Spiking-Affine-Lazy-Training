# 程式碼閱讀順序

架構審查重構(階段 0–8)做完後，從頭重新讀懂整個專案用的順序。自己讀，卡住再問。

## 怎麼讀

- 順序照依賴關係，由底往上排：每一站只用到前面讀過的東西。
- 每站先讀檔頭 docstring，再照列的順序讀檔案，最後看對應的測試。測試裡大多有手算的小例子，比程式本身好懂。
- 推導文件只在卡在「為什麼這樣算」的時候查，不用先讀完。
- 讀完用「讀完要能回答」自我檢查，答不出來的就是要問的地方。
- 提問時附檔案跟行號，例如 `float/affine.py` 第 147 行。
- 讀的過程找到的問題記在 `閱讀發現.md`,讀完全部再一起處理。

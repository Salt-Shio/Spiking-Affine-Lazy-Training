# 初始權重策略:參考文獻

`init_k`(權重初始化尺度)選值的兩篇依據。完整推導與本專案的 V1–V6 實測見
[`初始權重尺度推導.md`](初始權重尺度推導.md)。

## 1. Training Deep Spiking Neural Networks using Backpropagation

- Jun Haeng Lee, Tobi Delbrück, Michael Pfeiffer, 2016
- arXiv: [1608.08782](https://arxiv.org/abs/1608.08782)
- 用到的部分:**§4.2 Initialization and Error Normalization**
  - 變異數保持初始化 $w \sim \mathcal{U}[-\sqrt{3/M},\ \sqrt{3/M}]$($M$ = fan-in),
    等價於 $\mathbb{E}[w^2] = 1/M$ —— Glorot/He 家族的前向激活尺度守恆準則。
  - 門檻跟著權重尺度一起縮:$V_{th} = \alpha\sqrt{3/M}$,$\alpha \in [3, 10]$;
    真正的旋鈕是門檻/權重比值,不是權重絕對尺度。
  - 反向誤差逐層 rescale、門檻正則化(避免 SGD 把門檻壓到神經元死掉)。
- 在本專案的角色:`init_k = √3`(把上式換算到 $limit = init\_k/\sqrt{fan\_in}$)
  是「變異數保持」準則的落點;實測最佳的 `init_k = 5` 在同一個安全盆地內。

## 2. The Dormant Neuron Phenomenon in Deep Reinforcement Learning

- Ghada Sokar, Rishabh Agarwal, Pablo Samuel Castro, Utku Evci, ICML 2023
- arXiv: [2302.12902](https://arxiv.org/abs/2302.12902)
- 用到的部分:
  - **dormant score** $s_i^\ell = \dfrac{\mathbb{E}_x |h_i^\ell(x)|}{\frac{1}{H^\ell}\sum_j \mathbb{E}_x |h_j^\ell(x)|}$,
    $s_i \le \tau$ 即 $\tau$-dormant —— 活動在神經元間「怎麼分布」的形狀指標,
    平均 firing rate 看不到「少數飽和 + 多數休眠」。
  - **ReDo**:訓練中週期性重初始化休眠神經元的入向權重、出向權重歸零、
    清優化器狀態 —— 回收容量而不像整層 reset 那樣劇烈。
- 在本專案的角色:`salt_core/dormant.py` 是 dormant score 的實作(逐 epoch 寫進
  `metrics.csv`);ReDo 目前不做,列為「串更大網路(尤其深 FC)時再討論」的
  開放題(見推導文件步驟 8.4)。

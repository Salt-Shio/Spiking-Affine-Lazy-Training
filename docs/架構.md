# 架構

一個網路 = 一列 layer,層與層之間流動的是「事件流」(帶時間戳的 spike)。

- **`salt_core/`** —— 核心運算,自成封閉系統,不依賴 `data/` / `example/`。
- **`example/`** —— 拿 `salt_core` + `data` 組一個實際能訓練的模型的**範例**;換資料集 / 換架構改這裡,`salt_core/` 不動。

---

## 1. `salt_core/` —— 核心

### 資料流

```mermaid
flowchart TD
    RAW["原始事件<br/>event_times, x, y, c, n_real"] --> R2S["raw_events_to_stream"]
    R2S --> ES["EventStream<br/>event_times · event_source_idx · event_gain · n_real_events"]
    ES --> BQ["建佇列<br/>build_conv_queue_compressed / build_fc_queue<br/>connectivity/conv.py · fc.py → AffineMap (n_out, L)"]
    BQ --> RLF["run_layer_forward — chunk_scan.py<br/>逐 chunk: process_chunk (core.py) + atan_spike (surrogate.py)"]
    RLF --> LFR["LayerForwardResult<br/>spike_mask · s_spike · s_value · v_final"]
    LFR --> EXO["extract_output_events(_compressed) — layer_chain.py"]
    EXO --> ESN["EventStream + LayerDiag"]
    ESN -->|"下一層 — run_network 迴圈 (layers.py)"| BQ
    LFR -->|"最後一層"| DEC["decoder.py<br/>膜電位回歸 / 頻率 / 群體"]
    DEC --> SC["scores → loss"]
    RFT["receptive_field_tap_count — 找 L"] -. 佇列長度 .-> RLF
```

### 分層(按抽象層級切,不按 conv / FC 切)

1. **神經元行為 + 跑一層** —— `core.py` / `chunk_scan.py` / `surrogate.py`。
   一份共用模擬器(漏電、累加、放電、soft reset),不知道也不需要知道 conv / FC。
2. **每種 layer 怎麼從輸入 + 權重算自己的東西** —— `connectivity/conv.py`(壓縮佇列)· `connectivity/fc.py`。
   conv / FC 在這裡做的事本質不同,就讓它們不同;只在「吐出的形狀 `(n_out, L)` 的 `AffineMap`」上一致。
3. **層間接線** —— `layer_chain.py`。
   每個 layer 自己把 forward 結果吐成標準 `EventStream`;壓縮版的 local→global 索引查表收在函式內,不外洩成呼叫端的參數。
   **不是一個認識所有 layer 配對的萬能轉接器。**
4. **組網路** —— `layers.py` 的 `run_network` / `build_network`。
   吃一列 layer 把輸入流一層層轉換到底。加 pooling / residual / 新 layer 型別 = 照 `Layer` 約定寫一個新層物件,組裝邏輯一行不動。
   逐層超參(門檻 / `alpha` / `chunk_size` / init 尺度 / 容量)是**每個 layer 自己的欄位**,不是巨型 config 裡的一堆純量。

### `EventStream` —— 唯一的跨層約定

四欄:`event_times` · `event_source_idx` · `event_gain` · `n_real_events`。

`event_gain` 帶上一層每個 spike 事件自己 fire 那一刻的可微分強度 `s_spike`(forward 精確 = 1)——
下一層用離散 `event_source_idx` 從權重 gather,這條路徑對上一層權重的梯度天生是 0,`event_gain` 把它接回來(見 `docs/問題紀錄.md`)。

另加一份固定的 `LayerDiag`(spike 數 · firing rate · 佇列出界訊號 · 輸出上界出界訊號),每層 forward 都吐同樣這一份。

### 輸出編碼 = 可替換的解碼器

`decoder.py` 三種:膜電位回歸 / 頻率 / 群體,共同介面 `decode(LayerForwardResult) -> (scores, metrics)` + `validate(last_layer)`。

- 最後一層是**普通 layer**,沒有特殊型別;「不 fire / 純積分」只是它的門檻設定(`v_th = 1e9`)。
- 真正承重的介面是 `LayerForwardResult`(`v_final` · `s_value` · `spike_mask`);想要別的編碼,寫一個新解碼器,或直接在 loss_fn 裡讀 —— 解碼器不是唯一出口。

### layer 的自我初始化

- **找 L**(壓縮佇列長度):`receptive_field_tap_count` 純幾何 primitive + 訓練中偵測出界動態放大(`ConvLayer.grown_to_fit`)。
- **找 init_k**(初始權重尺度):**必填欄位,不校準**,委定值見 `docs/問題紀錄.md` §12(firing-rate 目標帶準則廢棄,固定
  `init_k = 5.0`,推導與實測見 `docs/math/初始權重尺度推導.md`)。自動找 k 的搜尋管線(舊 `calibrate.py`)已移除;
  `ConvLayer.calibration_measure` 這個量測 primitive 還留著,給 `example/tests/verify_init_k.py` 的獨立數值驗證用。

### 檔案

| 檔案 | 職責 |
|---|---|
| `core.py` | 單狀態仿射 LIF:`AffineMap` / `combine` / `process_chunk`(associative scan 內核)/ `mask_pad_events` |
| `chunk_scan.py` | `run_layer_forward` —— chunk 化序列迴圈,吐 `LayerForwardResult`;`run_layer_forward_traced`(共用內核,多疊逐步 `(v_steps, pointer)` 裸陣列,debug probe 用) |
| `surrogate.py` | `atan_spike` —— forward heaviside、backward ATan(`jax.custom_vjp`) |
| `connectivity/fc.py` | `build_fc_queue` |
| `connectivity/conv.py` | `build_conv_queue_compressed` + `receptive_field_tap_count`(純幾何) |
| `layer_chain.py` | `EventStream` + `extract_output_events` / `extract_output_events_compressed` |
| `layers.py` | `ConvLayer` / `FCLayer`(frozen dataclass;`forward` + `forward_traced`)· `run_network` / `run_network_traced` · `build_network` · `raw_events_to_stream` |
| `decoder.py` | 三種解碼器 + `validate` |
| `dormant.py` | `dormant_score`(逐神經元 `(n,)` 活動量 → dormant 統計,純歸約)/ `dormant_report`(逐層跑 forward 收逐神經元活動);ReDo 的前置 |
| `monitor.py` | `LayerForwardTrace`(逐步軌跡包)+ `resolve_ms_*`(掃描步指標 → 真實毫秒);`run_network_traced` 的 debug probe 用,不進訓練熱路徑 |

## 2. `example/` —— 組裝範例

`example/` 不是核心的一部分,是「拿 `salt_core` + `data` 組一個實際能訓練 N-MNIST 的模型」的範例。

```mermaid
flowchart TD
    CFG["configs/conv/*.yaml"] --> BN["build_network — example/models/conv_net.py"]
    BN --> LAYERS["[ConvLayer, ConvLayer, FCLayer]"]
    DS["NMNISTDataset — data/src/nmnist.py"] --> SPLIT["train / val split"]

    LAYERS --> WHILE
    SPLIT --> WHILE
    subgraph WHILE["train() while 外圈 —— 動態容量放大"]
        direction TB
        NET["ConvNetCompressed(layers) + optax.adam"] --> RE["run_epochs"]
        RE --> TS["train_step<br/>apply_batched → run_network → decoder.decode<br/>→ softmax_cross_entropy → grad → optax 更新"]
        RE -->|"每 epoch"| PE["evaluate_accuracy · dormant_report<br/>MetricsLog.finish_epoch · Checkpointer.save<br/>TraceProbe(probe_every>0)"]
        RE -->|"容量出界"| GROW["grown_to_fit → 退 checkpoint → 換新 layers 重編譯"]
        GROW --> NET
    end
    WHILE --> OUT["experiments/&lt;run&gt;/<br/>run.yaml · metrics.csv · params.npz · best_params.npz"]

    OUT -.-> EVAL["example/eval_test.py — test set 評估"]
    CFG -.-> VER["example/tests/verify_init_k.py — init_k 推導驗證"]
```

### 流程

- `configs/conv/*.yaml` 決定網路形狀 → `build_network` 吐 layer list(空間尺寸 / `ic` 串接 / FC `n_in` 全由 builder 推導)。
- `NMNISTDataset` 切 train / val。
- `train()` 的 **while 外圈 = 動態容量放大控制系統**:`run_epochs` 跑訓練;某 batch 壓縮佇列或輸出上界出界 → `grown_to_fit` 放大該層 → 退回最近的 checkpoint → 換新 layer list 重編譯續練。
- `run_epochs` 內圈:每 batch 算 loss(`apply_batched → run_network → decoder.decode → softmax_cross_entropy`)+ 梯度 + `optax` 更新;每 epoch 跑 val 評估 + `dormant_report` + `MetricsLog.finish_epoch` + `Checkpointer.save`。
- 輸出:`experiments/<run>/` 的 `run.yaml`(config 快照 + git commit + 最終容量 + 最佳指標)· `metrics.csv` · `params.npz` · `best_params.npz`。

### 檔案

| 檔案 | 職責 |
|---|---|
| `models/conv_net.py` | `build_network` / `build_decoder` / `ConvNetCompressed`(資料端事件格式 → `run_network` 的薄殼) |
| `train_conv_compressed.py` | 訓練 entrypoint:`train()` · `run_epochs` · 動態放大 while 外圈 |
| `metrics_log.py` | `MetricsLog` —— 逐 epoch 指標 → `metrics.csv` |
| `trace_probe.py` | `TraceProbe` —— `train.probe_every > 0` 時週期性對固定探測批跑 `run_network_traced`,逐神經元摘要 → `experiments/<run>/traces/summary.npz`,完整軌跡 → `full_epoch_XXX.npz`。forward-only,不進 `train_step` |
| `inspect_traces.py` | 讀 `traces/` 的 dump:休眠比例隨 epoch 的曲線(重用 `salt_core.dormant.dormant_score`)、整段沒醒的神經元、單神經元膜電位波形。獨立 entrypoint |
| `checkpoint.py` | `Checkpointer` —— params / opt_state / shuffle_key / epoch 存讀 |
| `eval_test.py` | 獨立 entrypoint:從 `experiments/<run>/` 重建網路 + 載權重 + test / val 評估 |
| `paths.py` / `utils.py` | repo 根 / dataset / experiments 路徑;seed / git commit hash |
| `tests/verify_init_k.py` | init_k 尺度推導的數值驗證(V1–V5) |

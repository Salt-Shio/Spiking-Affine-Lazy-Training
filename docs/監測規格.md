# SNN 訓練監測規格

訓練 / debug SNN 要記哪些資料。**討論中,非定案。**
背景:[`TODO.md`](TODO.md)「SNN 活動 monitor」;ReDo package 的前置。

## 原則

- **core 只負責把生資料傳出 graph,不 reduce、不預判分析。** 出 per-neuron-per-step 的 `(n, max_steps)` 陣列 + 能還原對應關係的 index 陣列(見「還原對應」節)。資料多亂沒關係,還原是純函式,helper 也放 `salt_core`。
- 放 `salt_core`:活動分布 / 膜電位 / 事件量是 SNN 通用除錯量,不是 example 專屬。`example/dormant.py` 的 `dormant_score`(`|h_i| / 層內 |h| 均值`)搬進來。
- `example` 只留:寫 `metrics.csv` / 圖、選 probe batch、梯度範數(要 `grad`,forward 外)。
- 約束:jit + vmap + grad 下 → 固定 shape、graph 內算完、`stop_gradient` 後回傳。monitor-on 因 shape 不同會另編一個函式 → 當週期性深 probe,不進熱迴圈。生陣列 × batch × layer 在 N-MNIST 規模一次 forward 約數 M float。

## 還原對應

`pointer` + `local_to_global_j` + `event_times` 湊齊 → 能還原「神經元 i 第 k 步 = 實際時刻 t」。純函式,helper 放 `salt_core`。

| 需要的 index | shape | 從哪拿 |
|---|---|---|
| `spike_event_idx` | `(n, max_steps)` | A,已有 —— spike 步落在佇列第幾欄 |
| `pointer` | `(n, max_steps)` | C,要把 scan carry 加進 output —— 每一步(不只 spike 步)從佇列第幾欄開始 |
| `local_to_global_j` | `(n, L)` | E,`cq` 已有,`ConvLayer.forward` 傳出來 —— 佇列欄 → 全域事件 index |
| `event_times` | `(n_events,)` | F 輸入流 —— 全域事件 index → ms |

## 一層 forward 有哪些資訊

`n` = 該層神經元數(conv:`OC*H_out*W_out`;fc:`n_out`)。
`max_steps` = `L`(ConvLayer)或 `ceil(輸入流長度 / chunk_size)`(FCLayer)。

### A. `LayerForwardResult` — `run_layer_forward` 回傳(chunk_scan.py)

已是穩定契約。`layer.forward` 內叫 `result`,但 `run_network` 只留**最後一層**的 → 要每層得改收集。

| 欄 | shape | 意義 |
|---|---|---|
| `spike_mask` | `(n, max_steps)` bool | 該步是否真的輸出一個 spike |
| `spike_event_idx` | `(n, max_steps)` int | spike 落在來源佇列第幾欄(fc/密集=全域事件 index;壓縮 conv=局部欄,要 `local_to_global_j` 查) |
| `s_spike` | `(n, max_steps)` float | spike 那刻自己的可微分強度,forward 精確 =1 |
| `s_value` | `(n, max_steps)` float | 該步視窗內所有有效事件的 s 加總(pad / spike 後已歸零) |
| `v_final` | `(n,)` float | 消化完 `max_steps` 步後的膜電位(**唯一被壓掉時間軸的量**) |

### B. `process_chunk` 內部量 — `ChunkForwardResult`(core.py)

每個 scan step 一份,目前只有 `v_final` 經 scan 疊出去。要別的得在 `run_layer_forward` 加 scan 輸出項 + `LayerForwardResult` 加欄。

| 量 | 疊起來 shape | 意義 |
|---|---|---|
| `chunk_result.v_final`(逐步) | `(n, max_steps)` | 每步結束的膜電位 = **完整 v 軌跡**,加這個就有 |
| `v_sequence` | `(n, max_steps, chunk_size)` | 假設不 reset 的逐事件電壓;`chunk_size=1` 時等於上一列 |
| `s_sequence` | `(n, max_steps, chunk_size)` | 可微分 spike 強度序列 |
| `spike_idx` | `(n, max_steps)` int | chunk 內第一次 spike 的索引(沒 spike = `chunk_size`);`==0` 即「首事件就 fire」 |

### C. `run_layer_forward` step 內部(scan carry)

目前不吐。`pointer` 疊起來可做「step → 佇列欄 → 全域事件 → `event_times`」對齊。

| 量 | shape | 意義 |
|---|---|---|
| `pointer` | `(n, max_steps)` int | 這步這顆神經元佇列已消化到第幾欄 |
| `n_valid_in_chunk` / `n_consumed` | `(n, max_steps)` int | 這步算數 / 吃掉幾筆事件 |

### D. `LayerDiag` — `layer.forward` 回傳第 3 元素;`run_network` 已收成 `diags` list

**現成的每層收集管道。** 現有 4 個純量:

| 欄 | 意義 |
|---|---|
| `spike_count` | `sum(spike_mask)` |
| `firing_rate` | `spike_count / (n * max(n_real_in, 1))` |
| `max_real_queue` | 逐神經元真實佇列長度的最大值(L 出界訊號;FC=0) |
| `n_out_spikes` | 這層真正吐幾筆 spike(沒被 `max_out_spikes` 截) |

### E. 佇列建構端

`ConvLayer.forward` 內叫 `cq`(`CompressedConvQueue`),沒外流 → 要拿得在 forward 內塞進 monitor。

| 欄 | shape | 意義 |
|---|---|---|
| `maps.a` / `maps.b` | `(n, L)` | 每顆神經元壓縮佇列的仿射映射(a=衰減、b=權重) |
| `local_to_global_j` | `(n, L)` int | (神經元, 局部欄) → 全域事件 index;空格 = `n_events` sentinel |
| `n_real_events` | `(n,)` int | 每顆神經元真正的合法 tap 數(不含 catch-up / identity) |

FC:`build_fc_queue` 只回 `AffineMap`,`(n, 全域事件數)`。

### F. 輸入 / 輸出事件流 — `EventStream`(layer_chain.py)

輸入流 = `layer.forward` 的參數;輸出流 = 回傳第 1 元素。`run_network` 迴圈中間層的沒留。

| 欄 | shape | 意義 |
|---|---|---|
| `event_times` | `(max_total_spikes,)` float | 排序遞增,前 `n_real` 筆真、後補 `1e12` |
| `event_source_idx` | `(max_total_spikes,)` int | 來源神經元 index |
| `event_gain` | `(max_total_spikes,)` float | 對應每筆事件的 `s_spike` |
| `n_real_events` | 純量 int | 真正 spike 數 |

### G. 靜態 config(層物件欄位,Python 端直接讀)

- ConvLayer:`ic h_in w_in oc k s p tau v_th alpha chunk_size L max_out_spikes init_k`;property:`h_out w_out n_neurons fan_in`
- FCLayer:`n_in n_out init_k tau v_th alpha chunk_size`;property:`n_neurons fan_in`

### H. 感受野幾何(conv.py,可直接 import 呼叫)

`receptive_field_tap_count(x, y, S, P, H_out, W_out, K, n_real)` → `(H_out*W_out,)` int:每個空間輸出位置有幾筆真事件是合法 tap(= firing rate 正規化的分母 / 「機會數」)。

### I. surrogate 斜率(surrogate.py)

`_atan_spike_bwd` 公式:`(alpha/2) / (1 + (pi·alpha/2·x)^2)`,`x = v - v_th`。對實際命中的 `x` 算這個 = dead-gradient 檢查。

## 要記什麼(圈選)

`[定]` 要 / `[候]` 待定。都用完整軌跡(不 reduce 掉 `max_steps`)。

**Tier 1 純量,永遠開**
- `[定]` D 的 4 個(已有)+ `v_final` mean/std/min/max + 首事件 fire 比例(`spike_idx==0`,問題紀錄 §12)+ overflow / NaN flag + 事件放大比 `n_out/n_in`

**Tier 2 `(n,)` 或 `(n, max_steps)` 陣列(ReDo / L 收縮 / dormant 用;規模小)**
- `[候]` per-neuron spike count、per-neuron `v_final`、per-neuron real queue len(E.`n_real_events`)
- `[候]` 完整 v 軌跡(B 的第一列)、`s_value` 軌跡(A,已現成)

**Tier 3 opt-in**
- `[候]` surrogate 斜率健康度(I)、firing rate / `v` 直方圖或 percentile

**消費端 `example`**
- `[候]` 逐層 `‖grad_W‖`、dormant fraction 曲線、事件量逐 epoch(→ L 收縮時機)
